# 리눅스 명령어 조사: top, ps, jobs, kill

오픈소스SW와 파이썬 프로그래밍 - 과제 1

리눅스에서 실행 중인 프로세스(작업)를 확인하고 관리할 때 사용하는 명령어 4가지를 조사했습니다.

---

## 1. `top` 명령어

`top`은 현재 시스템에서 실행 중인 프로세스들을 **실시간으로** 보여주는 명령어입니다. CPU 사용률, 메모리 사용률이 높은 프로세스부터 순서대로 정렬해서 보여줍니다.

### 사용법

```bash
top
```

### 주요 화면 정보

| 항목 | 설명 |
|------|------|
| PID | 프로세스 고유 번호 |
| USER | 프로세스를 실행한 사용자 |
| %CPU | CPU 사용률 |
| %MEM | 메모리 사용률 |
| TIME+ | 누적 CPU 사용 시간 |
| COMMAND | 실행 중인 명령어 이름 |

### 자주 쓰는 옵션

- `top -u 사용자명` : 특정 사용자의 프로세스만 보기
- `top -n 1` : 한 번만 갱신하고 종료 (반복 갱신 안 함)
- `q` 키 : top 화면 종료

> 💡 **참고** : `top` 실행 중에 `k`를 누르고 PID를 입력하면 화면에서 바로 프로세스를 종료할 수도 있습니다.

---

## 2. `ps` 명령어

`ps`(process status)는 현재 실행 중인 프로세스의 상태를 **한 번** 출력해주는 명령어입니다. `top`과 달리 실시간 갱신은 되지 않고, 스냅샷처럼 현재 상태만 보여줍니다.

### 사용법

```bash
ps [옵션]
```

### 자주 쓰는 옵션

| 옵션 | 설명 |
|------|------|
| `ps` | 현재 터미널(쉘)에서 실행 중인 내 프로세스만 표시 |
| `ps -e` 또는 `ps -A` | 시스템의 모든 프로세스 표시 |
| `ps -ef` | 모든 프로세스를 부모 프로세스 정보까지 포함해서 자세히 표시 |
| `ps aux` | 사용자, CPU/메모리 사용률 등을 포함해 자세히 표시 (가장 많이 사용됨) |

### 예시

```bash
ps aux | grep python
```
→ 현재 실행 중인 프로세스 중 이름에 `python`이 포함된 것만 찾아서 보여줍니다.

---

## 3. `jobs` 명령어

`jobs`는 **현재 쉘(터미널)에서 실행 중이거나 중지된 작업(job) 목록**을 보여주는 명령어입니다. `&`를 붙여 백그라운드로 실행한 작업이나, `Ctrl+Z`로 중지시킨 작업을 확인할 때 사용합니다.

### 사용법

```bash
jobs
```

### 작업을 백그라운드로 보내는 방법

```bash
sleep 100 &      # 명령어 뒤에 & 를 붙이면 백그라운드 실행
jobs              # 실행 중인 작업 목록 확인
```

출력 예시:
```
[1]+  Running    sleep 100 &
```

### 관련 명령어

- `fg %1` : 1번 작업을 다시 화면 앞(foreground)으로 가져오기
- `bg %1` : 중지된 1번 작업을 백그라운드에서 계속 실행
- `Ctrl+Z` : 실행 중인 작업을 일시 중지(stopped 상태로)

---

## 4. `kill` 명령어

`kill`은 실행 중인 프로세스에 **신호(signal)를 보내서 종료시키는** 명령어입니다. 이름은 "kill"이지만 단순 종료뿐 아니라 다양한 신호를 보낼 수 있습니다.

### 사용법

```bash
kill [옵션] PID
```

### 자주 쓰는 신호

| 신호 | 번호 | 설명 |
|------|------|------|
| SIGTERM | 15 | 기본값. 프로세스에게 "정상적으로 종료해라"라고 요청 |
| SIGKILL | 9 | 강제 종료. 프로세스가 무시할 수 없음 |
| SIGSTOP | 19 | 프로세스를 일시 정지 |

### 예시

```bash
kill 1234          # PID 1234번 프로세스에 종료 신호(SIGTERM) 전송
kill -9 1234       # PID 1234번 프로세스 강제 종료(SIGKILL)
kill %1            # jobs 명령어로 확인한 1번 작업 종료
```

> ⚠️ **주의** : `kill -9`는 프로세스를 정리할 시간을 주지 않고 즉시 강제 종료하므로, 저장되지 않은 데이터가 사라질 수 있습니다. 가능하면 먼저 `kill`(SIGTERM)을 시도하고, 반응이 없을 때만 `-9`를 사용하는 것이 좋습니다.

---

## 정리

| 명령어 | 역할 |
|--------|------|
| `top` | 프로세스를 실시간으로 모니터링 |
| `ps` | 현재 프로세스 상태를 한 번 출력 |
| `jobs` | 현재 쉘에서 실행/중지된 작업 목록 확인 |
| `kill` | 특정 프로세스에 종료(또는 다른) 신호 전송 |
